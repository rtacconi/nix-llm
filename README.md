# NixSandbox

A Linux execution sandbox for code generated by LLM agents. It has three parts: a
Rust supervisor that sets up the isolation from kernel primitives (namespaces,
cgroup v2, Landlock, seccomp-BPF, pidfds), immutable runtimes built with Nix,
and an asyncio Python orchestration service that agents call.

**Status:** Phase 1–3 (design, design review and implementation plan). There is
no implementation code yet. The prototype (Phase 4) starts at milestone M0 in
[docs/14-roadmap.md](docs/14-roadmap.md).

## Platform

The runtime needs Linux 6.6 or newer (see [kernel baseline](docs/03-kernel-primitives.md#kernel-baseline)).
On macOS you can edit the code and run the platform-neutral unit tests. Integration
and security tests need a Linux host or a NixOS VM.
